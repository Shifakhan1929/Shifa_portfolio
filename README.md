# Shifa Portfolio 💻

A modern frontend project built with React and TypeScript, exploring interactive user interfaces, responsive layouts, and component-based development.

##  Built With
- React
- TypeScript
- TanStack Start
- TanStack Router
- Tailwind CSS
- Vite
- Recharts
- Lucide React

##  Getting Started

Clone the repository:

```bash
git clone https://github.com/Shifakhan1929/Shifa_portfolio.git
cd Shifa_portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

##  Testing

```bash
npm run test
```

##  Build

```bash
npm run build
```
